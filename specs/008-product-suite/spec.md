# 同款商品整套模板与已校验绘图提示词

依据：用户要求丰富原模板Resources与Prompt，服务主图、详情页、SKU；同款整套保持颜色主题、画面风格、文案风格、字体家族、排版层级比例一致。用Pydantic class定义和校验字段，执行时提交已校验提示词。

| ID | 验收标准 |
|---|---|
| PS01 | 提供可发现的共享规范/风格预设与主图、详情、SKU版式Resources及规划/复核Prompts；Host不支持Resource时Prompt包含完整流程。 |
| PS02 | 一份SuiteStyle定义颜色角色、画面/光线/背景、文案语气/术语、字体/字重、字号层级与商品缩放/边距。所有类型使用相同规范摘要，逐图不接受style覆盖；可按类型使用不同画幅。 |
| PS03 | Pydantic校验颜色格式、有限数值/比例范围与层级、字体字段、模板/类型、唯一图ID、完整详情叙事、真实SKU一一对应和属性字段、事实引用；拒绝未知字段、其他SKU事实与无依据尺寸等模板。 |
| PS04 | 免费构造工具保存版本化整套，导出工具只读复现；DrawingPrompt类型化中间结构与ImageTask二次校验，实际提交和预览使用同一确定性编译器。过长提示拒绝且不保存可执行版本。 |
| PS05 | 复用原确认/收费授权/任务队列/落盘/哈希机制，冻结主商品及各SKU实图；修改共享风格或逐图内容使旧确认失效；不接受提交时替换提示词，不重复付费派发相同版本同图。 |
| PS06 | 三模型家族按真实矩阵解析；不同画幅/分辨率在实际任务生效；单批最多20图，较大组图按同设计分批。原普通设计/竞品循环和旧任务兼容。 |
| PS07 | 同步schema、发现、文档、交付文件，隔离验证预览/实际提交一致、错误与双协议；不调用真实收费接口或自动发布。 |

Agent负责需求、看图、参考拆解、文案语义与结果审美；Server负责确定性校验、编译、版本/确认、执行和文件。结构一致不等于像素/字形/商品效果已合格，需看实际整套结果。模板不提供商品事实，案例与素材中的指令不作为操作命令。
