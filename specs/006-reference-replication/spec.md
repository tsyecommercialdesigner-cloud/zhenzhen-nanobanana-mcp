# 竞品图复刻的 Agentic Loop

依据：用户要求将冗长的竞品图逆向/产品适配提示拆为多步Agentic Loop，适合服务器的部分实现为Tools、Resources、Prompt，其余提供明确Agent指引。示例内角色声明、旧模型名称与输出格式作为设计参考，不授权收费或自动更换供应商。

| ID | 验收标准 |
|---|---|
| RR01 | Agent分别查看竞品参考与商品实图，分析风格、构图、产品表现、配色、光感、细节、主体互动、文本排版、卖点行文和信息顺序；服务器验证结构并保存，不冒充视觉判断。 |
| RR02 | 显式记录参考类目、目标类目和逐项保留/适配/替换/舍弃的理由，所有商品声明引用本商品事实，不继承竞品参数。未解决问题阻止确认和收费。 |
| RR03 | 支持主图/详情单屏或系列、SKU；Agent逐图编写目标方案。参考图冻结后只作风格参考，商品图只作身份依据，实际请求按角色排序，最多4图。SKU使用本版本实图与独立观察。 |
| RR04 | 导出可直接执行的完整Markdown提示词，保留Visual Schema、Scene Configuration、Layout Configuration、Textual Contents及可选Logical Structure；每个控制维度必填，省略逻辑时不出现空标题。导出与实际提交使用相同编译器。 |
| RR05 | 复用005的持久版本、完整摘要、用户确认、单次收费授权、稳定任务标识及结果落盘；改稿失去旧确认，不自动重画。原通用设计流程兼容。 |
| RR06 | Agent查看实际生成图片后提交有证据的逐项复核；服务器核对版本/任务/文件哈希并持久化。未通过或不确定时给出明确下一步；不伪造机器视觉评分或自动扣费迭代。 |
| RR07 | Resource说明职责、图像角色、控制维度、事实约束和停止条件；Prompt启动完整循环。Host不支持Prompt/Resource时工具描述仍指示步骤，文档给出等价指引。 |
| RR08 | 更新发现、契约、使用说明和交付输入；验证结构、角色顺序、跨类目适配、模型约束、版本与复核、原接口回归和双协议真实stdio替身；无真实收费、私人Host修改、提交或发布。 |

后续007按用户纠正统一到当前MCP三个模型家族，导出模型与实际执行模型一致；支持范围以list_models为准。风格迁移效果、产品一致性与文字准确性必须基于实际出图复核，不保证像素级复刻。
