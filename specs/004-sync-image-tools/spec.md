# 可选择的同步出图与等待

依据：用户要求增加同步出图，原异步并发工具继续保留。原003规范关于只公开异步入口的限制在本功能范围内被此要求取代，其余上游、持久化和防重契约不变。

| ID | 验收标准 |
|---|---|
| ST01 | generate_images 接收与异步相同的三元组及1–12项任务，等待所选组全部进入终态；只有全部成功才返回成功和已落盘图片路径。编辑由reference_images与原模型路由控制。 |
| ST02 | 同步/异步共享SQLite、全批冲突原子性和并发限额；等待时不阻塞事件循环，不新增上游重试。改变等待时限不改变任务指纹。 |
| ST03 | wait_image_tasks 只等待明确指定的1–100个已有任务，不提交新任务；缺失、空列表、重复ID和错误命名空间明确失败。 |
| ST04 | wait_timeout_seconds为严格整数1–1200、默认600，从开始本地等待计时；包含排队时间，与单任务服务超时独立。到期返回isError及wait_timed_out=true和当前完整状态，不能伪装已出图成功。 |
| ST05 | 等待到期/客户端取消只停止此次等待，不取消或重交队列任务。可用原身份查询/等待；服务进程被Host关闭仍按原恢复规则处理。 |
| ST06 | failed/unknown/cancelled保留所有结果并isError=true；全部终态但失败不算等待超时。重复/跨入口及跨实例等待不重复出图，成功数据与异步可互查。 |
| ST07 | 原6工具不删除或改签名；新增2工具及发现说明、Prompt/Resource、生成契约、静态指南和双协议替身测试同步。无真实收费/Host配置修改、D盘安装更新或发布。 |

同步是MCP一次调用内等待，仍由原后台worker执行；不是新的供应商同步/异步接口，不承诺长时间Host不断线。已发布v0.2.1仍是原6工具版本，新能力在开发工作区，另行发布安装后才生效。
