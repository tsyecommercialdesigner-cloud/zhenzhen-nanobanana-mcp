# 首版需求 — 家居日用百货电商绘图

> 历史 0.1 设计：当前 API 矩阵及异步工具已由 [003 规范](../003-async-image-tasks/spec.md) 取代。保留下方内容供历史追溯，不代表当前能力。

依据：2026-10-14 用户明确要求与 `docs/api-endpoint.md`；后续编辑接口示例优先于旧文档。本文不是已安装 spec-kit 的产物；当前项目未初始化 spec-kit、Git 或任务数据库。

## 目标与范围

本地 stdio MCP 服务，接入 Cherry Studio、Codex、Claude Code、DSH；Python 3.12.14、uv、FastMCP 为指定约束。提供主图、详情页（卖点、材质、尺寸、使用步骤）、场景图、营销海报和参考图修改；重点是家居日用百货。生成计划不调用模型，真正出图由明确的批量工具调用触发。

三个基础模型均支持文生图和编辑：`gemini-3.1-flash-lite-image`、`nano-banana-pro`、`gemini-nano-banana-2.1`。2026-10-15 用户增加 `nano-banana-pro-2k`、`nano-banana-pro-4k`、`gemini-nano-banana-2.1-2k`、`gemini-nano-banana-2.1-4k`，接口与基础版本一致。三种 API 格式是模型的已声明能力；本服务提供 DALL·E、OpenAI Chat、Gemini 三个适配器，默认 DALL·E。客户端名称不是远程部署要求。

## 用户场景

2026-10-15 用户指定默认模型改为 `gemini-nano-banana-2.1`；未传 model 的新调用使用该基础版，显式尺寸自动路由到对应2k/4k。显式指定其他模型仍有效，默认接口保持DALL·E。

- US1：输入商品名称、已核实卖点、页面类型和参考图，先得到可修改的绘图计划。
- US2：提交 1–12 张不同提示词的批次，选择模型和 API 格式，自动保存实际图片，返回绝对路径、图片大小和 SHA-256。
- US3：用本地商品图或公开 HTTP/HTTPS 图片作为参考修改，保留商品外形/颜色/品牌细节；这属于提示词约束，不保证模型输出绝对一致。
- US4：某张失败时保留已成功图片及批次清单；以相同请求编号查询，不重复扣费调用。

## 边界与假设

- 不直接发布/上传电商平台，不接入店铺账号，不生成虚假的平台合规承诺；具体平台尺寸、文案由用户决定。
- 2026-10-15用户进一步要求取消全部参考图目录白名单：读取服务账号可读的图片绝对路径，旧NANOBANANA_INPUT_DIRS忽略；支持公开HTTP/HTTPS图片URL。输出仍为outputs/，工具不能任意指定输出目录或覆盖旧图。
- 单批 1–12 项，每项最多 4 张参考图，每张最多 20 MiB、合计最多 40 MiB；输出图片最多 32 MiB、最多 64M 像素。每个上游请求最多接收 80 MiB JSON。最多 2 个出图请求同时运行（进程级）。同输出目录可多进程查询/防重，但并发限制不跨进程。
- 批量是一组独立请求，不假定上游支持 `n`、任务轮询或幂等键。无收费 POST 自动重试。取消/崩溃时上游可能已收费，未完成批次不会自动恢复。
- 用户补充编辑样例为 form-data，随后明确统一使用 `aspect_ratio`（上游也会将 `size` 转换为此字段）；样例未给文件字段。本服务假设单图 `image`、多图 `image[]`，真实上游待验证。
- Chat/Gemini 请求图片参数及响应图片结构采用对应官方格式及受控样例；贞贞实际兼容性尚待验证，不能把模拟测试称为真实业务成功。
- 密钥加载遵从 2026-10-14 更新的项目约定：固定项目 `.env` → 进程环境 → Windows 当前运行账号 HKCU Environment，字段存在但空/非法、重复、文件不可读或解析错误不回退；必需密钥全部缺失拒绝启动。不搜索 Host 工作目录/父目录，不修改用户环境，不展开变量。Host 模板默认不转发后端密钥，只交付空值 `.env.example`。

## 可测试验收

| ID | 验收标准 |
|---|---|
| AC01 | 模型发现包含准确的七个模型及三种格式，未知模型/比例/格式被拒绝。 |
| AC02 | 商品主图与详情计划包含用户提供信息，不捏造认证、尺寸、销量；无业务联网。 |
| AC03 | 生成使用 `/v1/images/generations` JSON，编辑使用 `/v1/images/edits` 文件表单；均传 `aspect_ratio`；Chat/Gemini 映射分别验证。 |
| AC04 | 1–12 项批量成功/部分失败/全部失败分别返回准确状态，图片自动保存、扩展名取自内容、绝对路径及校验值可核对。 |
| AC05 | 请求编号对内容指纹绑定；重复同内容返回持久结果，不再次 POST；不同内容冲突被拒绝；未完成批次不重发。 |
| AC06 | 输出路径越界、私网URL/重定向、无效图片、超限数据、缺失密钥均返回脱敏错误；参考图无目录白名单，下载不携带业务密钥。 |

| AC08 | 实际 stdio 子进程协议发现及调用通过，结构化输出符合 schema；检查无需密钥且不调用收费 API。 |
| AC09 | 四个 Host 模板与手册一致；静态检查、CLI 注册、真实 Host 联调分开报告。 |
| AC10 | 白名单打包拒绝越界/缺失/重复/凭证，隔离空缓存联网安装与协议检查通过；保留开发环境，不默认交付成员 ZIP。 |
| AC11 | 验证文件优先与逐级缺失回退、空值/格式/重复/读写权限/解析错误不回退、缺失必需字段失败、Host cwd 诱导文件忽略、错误脱敏；升级保留 `.env` 内容及 ACL，白名单拒绝非空 `.env.example`。 |
| AC12 | 新ZIP所有文件带唯一顶层zhenzhen-nanobanana-mcp/前缀，解压到父目录自动创建项目目录，不要求mkdir或形成重复嵌套；带前缀白名单精确一致，隔离安装/协议和升级.env保留通过。 |

| AC15 | HTTP/HTTPS参考图下载及重定向可用，支持同项本地与URL混合编辑；图片请求不携带后端密钥，下载失败/非图片时收费前拒绝；网络安全检查继续有效。 |

显式分辨率字段为每项可选 `resolution: {width, height}`，宽高必须是正整数像素，不接受布尔值、字符串、浮点或未知字段。免费计划允许统一指定并传入每项。2048px 使用2k已获用户确认。直接指定变体且无 resolution 时保留变体；有 resolution 时按同一模型家族重新选档。该字段只控制模型选择，不改变 aspect_ratio，不传上游 size/width/height，也不承诺精确输出像素或执行缩放。
